# 流程拆解方法笔记

从「灵巡流程图专用文档」中提炼的"产品拆阶段、阶段拆子流程、子流程配泳道图"方法，及其在应急预案编制流程中的应用落地。

## 核心方法

一句话：**先拆阶段、再拆子流程、每个子流程配一张泳道图。**

1. 阶段的划分依据是**价值流（产出物交接链）**，不是功能菜单
2. 子流程的颗粒度是**"一个动作 + 一个产出"**，动词开头、可独立验收
3. 每个子流程固定配一张**泳道图**（横向步骤顺序，纵向责任方）
4. 所有流程图**集中维护在一篇专用文档**，规则写在文档开头，不散落到各处

## 反直觉要点

- 应急预案是**事件驱动的支线**，不是主流程的"阶段九"——直接塞进去是错的
- 泳道图里最该画细的是**判断节点和等待节点**，动作步骤反而可以略
- 流程文档要写明**边界**：止于定稿还是含备案，必须显式声明
